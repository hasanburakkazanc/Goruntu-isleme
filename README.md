# 🖼️ Görüntü İşleme Çalışmaları / Image Processing

OpenCV, NumPy ve Matplotlib kullanarak görüntü işleme temellerinden ileri seviye konulara doğru hazırlanan haftalık Jupyter Notebook çalışmaları.

*(Weekly Jupyter Notebook exercises from image processing fundamentals to practical applications using OpenCV, NumPy, and Matplotlib.)*

---

## 📁 İçerik / Contents

| Klasör / Folder | Konular / Topics |
|---|---|
| `Görüntü İşlemee/ders-1` – `ders-3` | Görüntü okuma, piksel matrisleri, renk uzayları *(Image I/O, pixel matrices, color spaces)* |
| `Görüntü İşlemee/ders-4` – `ders-5` | RGB kanalları, matris manipülasyonu, gri tonlama *(RGB channels, grayscale conversion)* |
| `Görüntü İşlemee/ders-6` | Eşikleme (Thresholding / Binary) ve Haar Cascade ile yüz tespiti *(Face detection)* |
| `Görüntü İşlemee/ders-7` & `Hafta_8` | Bulanıklaştırma (Blurring), kenar tespiti ve plaka işleme *(Edge detection & license plate processing)* |
| `ek-notebooklar/` | Ek hafta pratikleri (Hafta 3, 6, 7 ve NumPy ile temel YSA örneği içeren Hafta 9) |

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack
- **Python 3** & **Jupyter Notebook**
- **OpenCV (`cv2`)**
- **NumPy**
- **Matplotlib**
